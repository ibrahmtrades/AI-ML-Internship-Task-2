## Task 2: Tesla Stock Price Prediction

This project uses machine learning to predict Tesla stock prices based on historical market data.

### Dataset:
Yahoo Finance (TSLA stock data)

### Features:
- Open
- High
- Low
- Close
- Volume
- Moving Averages (MA50, MA200)

### Model:
- Random Forest Regressor

### Visualizations:
- Candlestick chart
- Moving averages trend
- Actual vs predicted price graph

### Outcome:
The model captures stock trends using technical indicators and provides improved predictions using ensemble learning.
